## ⚡ How to Run Directly

### Option 1: Double-Click (Zero Setup)
- Double-click **`launch_portfolio.bat`** (or double-click **`index.html`**).
- The website will open instantly in your default web browser without needing any server or dependencies.

### Option 2: Local Python Server
- Double-click **`start_local_server.bat`**, or run:
  ```powershell
  python -m http.server 3000
  ```
- Open [http://localhost:3000](http://localhost:3000) in your browser.
