# Playfoliyo — Sports Networking & Career Platform

> "LinkedIn for Sports" connecting athletes, scouts, and event organizers.  
> **Tech Stack:** MongoDB, Express.js, React.js, Node.js, JWT Authentication, REST APIs.  
> **GitHub:** [harshi2410/Playfoliyo](https://github.com/harshi2410)

## Core Capabilities
- Athlete Resume Builder with verified statistics, awards, and video highlights.
- Interactive team discovery feed connecting clubs with prospective players.
- Real-time squad messaging and tournament registration workflows.
