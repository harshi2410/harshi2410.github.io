# Kshetra — Geospatial & AgriTech Land Intelligence

> Geospatial analysis platform for field monitoring, terrain topography, and NDVI spectral vegetation indices.  
> **Tech Stack:** Python, GeoPandas, Shapely, GIS, NumPy, Pandas, REST APIs.  
> **GitHub:** [harshi2410/Kshetra](https://github.com/harshi2410/Kshetra)

## Architecture
- Ingests multispectral satellite bands to compute Normalized Difference Vegetation Index (NDVI).
- Generates field boundary polygon GeoJSON overlays with elevation contours.
- Yield forecast estimation based on historical precipitation and temperature anomalies.
