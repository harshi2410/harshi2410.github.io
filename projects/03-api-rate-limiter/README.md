# API Rate Limiting Middleware Security Logger

> Express.js middleware for college examination (TAE) systems with live sandbox.  
> **Tech Stack:** Express.js, Node.js, JavaScript, Atomic JSON DB, Security Protocols.  
> **GitHub:** [harshi2410/API-Rate-Limiting-Middleware-Security-Logger](https://github.com/harshi2410/API-Rate-Limiting-Middleware-Security-Logger)

## Features
- Sliding-window and token-bucket rate limiting per IP / API client key.
- Dynamic IP blacklisting upon exceeding configurable anomaly thresholds.
- Zero external database dependency — high-speed atomic JSON persistence engine.
